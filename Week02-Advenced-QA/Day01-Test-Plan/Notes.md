### Test Plan

- Test plan, planlanan test faaliyetlerinin kapsamını, yaklaşımını, kaynaklarını ve zaman çizelgesini tanımlayan temel QA dokümanıdır.
- Test ekibine, Yazılım Geliştirme Yaşam Döngüsü (SDLC) boyunca rehberlik eden stratejik bir belgedir.
- İyi hazırlanmış bir test planı; test sürecinin kontrollü ilerlemesini sağlar, riskleri azaltır ve test çalışmalarını iş hedefleriyle uyumlu hale getirir.

**Test planı oluşturmanın temel adımları:**
1. Define the relase scope
2. Define test objectives
3. Design the test strategy
4. Determines test deliverables
5. Plan the test environment and test data
6. Schedule timelines
