## Week 03 - API Testing with Postman

This week focuses on understanding and practicing **API testing fundamentals** from a QA perspective.
The goal is to validate not only status codes, but also response structure, data types, and basic API behavior.

------

### Covered Topics
- REST API basics
- HTTP methods: GET, POST, PUT, DELETE
- Status codes (200, 201, 400, 404)
- JSON response structure
- Basic negative scenarios
- Intro to Postman Tests (assertions)

-------

### Tools Used
- Postman
- JSONPlaceholder (public test API)
- Github (documentation & portfolio)

--------

### Folder Structure
- **Day01-API-Basics**
    - Basic GET and POST requests tested with Postman
    - Successful requests and negative POST scenarios documented

- **Day02-Status-Codes**
    - Negative API scenarios tested
    - Invalid ID format, non-existing resource, and wrong endpoint cases

- **Day03-Post-Put-Delete**
    - POST,PUT, and DELETE operations on comments endpoint
    - Resource creation, update, and deletion scenarios

- **Day04-JSON-Response-Validation**
    - API response analyzed in JSON format
    - Field structure and data type validation performed

- **Day05-Mini-API-Test-Checklist**
    - Mini API test checklist created from a QA perspective
    - Basic Postman test assertions added

---------

### What I Practiced
- Sending API requests with GET,PSOT,PUT,and DELETE methods
- Testing negative API scenarios and error responses
- Validating JSON response structure and required fields
- Creating QA-focused API test checklists
- Writing basic assertions using Postman Test tab

----------

### Outcome
At the end of this week, I can:
- Performed manual API testing using Postman
- Test both positive and negative API scenarios
- Validate API responses beyond status codes
- Apply basic automated checks for API responses

### HTTP Headers (Basic Awareness)
- Headers, client ile server arasında ek bilgi taşır.
- En yaygın kullanılan header: Content-Type: application/json
- Authorization header genelde token bazlı kimlik doğrulama için kullanılır.
- Fake API'lerde header zorunlu olmayabilir.
