## JSON & Response Validation

- API response JSON formatındadır.
- Response bir array olarak dönmektedir.
- Her obje aşağıdaki alanları içermektedir:
    - postId (number)
    - Id (number)
    - name (string)
    - email (string)
    - body (string)

QA validates not only status codes but also response structure and data types.
