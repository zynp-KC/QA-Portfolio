## Day 03 – POST, PUT, DELETE Requests


### POST – Create Comment
- **Endpoint**: /comments
- **Method**: POST
- **Expected**: 201 Created
- **Result**: 201 returned


### PUT – Update Comment
- **Endpoint**: /comments/1
- **Method**: PUT
- **Expected**: 200 OK
- **Result**: 200 returned


### DELETE – Delete Comment
- **Endpoint**: /comments/1
- **Method**: DELETE
- **Expected**: 200 OK
- **Result**: 200 returned
